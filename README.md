
# 🛍️ ShopEasy - Mini E-Commerce Website

ShopEasy is a modern, responsive mini e-commerce web application built using HTML, CSS, and JavaScript. It provides an interactive shopping experience with dynamic product rendering and shopping cart functionality.

## ✨ Features

- Dynamic product rendering using JavaScript objects
- Add products to shopping cart
- Increase and decrease product quantity
- Remove products from cart
- Automatic cart count and total price calculation
- Product search functionality
- Category-based product filtering
- Price sorting (Low to High / High to Low)
- Free shipping on orders above ₹999
- Checkout preview modal
- LocalStorage to save cart items
- Responsive design for mobile and desktop
- Demo order placement

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- LocalStorage
- JavaScript Array Methods

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start exploring products and using the shopping cart.

## 🛒 Shopping Features

Users can browse products, search for items, filter products by category, add products to their cart, manage quantities, and preview their order before checkout.

## 📱 Responsive Design

The website is designed to work on desktop, tablet, and mobile devices.

## ⚠️ Note

This is a frontend demonstration project. The checkout process is for demonstration purposes only. No real payments are processed.
